# ASEAN Visa & Travel Guide

This is an offline-friendly copy of the static site. Extract the ZIP and open `index.html` directly; its local CSS, JavaScript, and favicon use relative paths. No framework, install, or build step is required.

The published website is separate and available at https://asean-guide-gqcfjrkc.manus.space/ . The app itself can be opened offline, but its official visa portal and source links require internet access. Visa guidance is indicative; confirm requirements with official authorities before travel.
